# risovalnik-pipisek
Что делаем: минималистичный Paint в браузере, один холст, никаких аккаунтов и облаков. MVP (обязательно): - Холст на всю доступную область, рисуем мышью и пальцем (pointer events). - Кисть: выбор цвета и толщины, плавная линия без «точек» — интерполяция между событиями. - Ластик — тот же инструмент,
