| Идея | Что делаем: минималистичный Paint в браузере, один холст, никаких аккаунтов и облаков. MVP (обязательно): - Холст на всю доступную область, рисуем мышью и пальцем (pointer events). - Кисть: выбор цвета и толщины, плавная линия без «точек» — интерполяция между событиями. - Ластик — тот же инструмент, но рисует цветом фона. - Палитра: несколько готовых цветов + свой через color input. - Undo / Redo — стек снимков холста, ограничить шагов 20, чтобы память не жрало. - Очистить холст (с подтверждением). - Сохранить в PNG — через toDataURL и скачивание файла. Технически: чистый HTML + CSS + JS, canvas 2D, без библиотек. Файлы: index.html, style.css, app.js.
